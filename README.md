# 🌹 给特别的你 - 浪漫表白页面

一个精美的表白页面，包含动态效果和交互功能。

## ✨ 功能特性

- 🎨 粉色渐变背景
- 💖 漂浮爱心动画
- 💓 心跳动画效果
- 🎯 交互式按钮（"我愿意"和"再考虑一下"）
- 🎆 点击"我愿意"后的烟花庆祝效果
- 📱 响应式设计，支持手机访问

## 🚀 快速开始

### 方法1：直接访问在线版本
如果已部署到 GitHub Pages，直接访问链接即可。

### 方法2：本地运行
1. 下载所有文件
2. 启动本地服务器：
   ```bash
   powershell -ExecutionPolicy Bypass -File smart-server.ps1
   ```
3. 在浏览器中访问显示的地址

### 方法3：打开 HTML 文件
双击 `tmp.html` 文件在浏览器中打开

## 📋 文件说明

- `tmp.html` - 主页面文件
- `smart-server.ps1` - 智能服务器脚本
- `simple-server.ps1` - 简单服务器脚本
- `README.md` - 说明文档

## 💡 部署到 GitHub Pages

1. 创建 GitHub 仓库
2. 上传所有文件
3. 在 Settings > Pages 中启用
4. 选择源分支并保存

## 🎭 使用说明

1. 打开页面后会看到浪漫的表白文字
2. 点击"我愿意！"查看庆祝效果
3. 尝试点击"再考虑一下"，按钮会移动
4. 在成功页面可以点击"再看一遍"重新体验

## 💌 自定义内容

可以修改 `tmp.html` 中的文字内容：
- 修改表白文字（第168-171行）
- 修改成功页面文字（第186-188行）
- 更改颜色主题（CSS样式）
